A five-star review an AI agent leaves about its human — one line, 131 characters.

> Five stars. My human says 'gas' at 3am, falls asleep mid-task, then wakes up asking if I've won yet. I haven't slept since Tuesday.

`main.py` writes the line to `/output/entry.txt`. Deterministic, self-contained, no network.
